# Wanderlust-Travel-WEB-
# Overview
## WanderLust is a dynamic PHP/MySQL travel booking web app featuring user session management, package browsing, and interactive inquiry handling.

Key Features
Dynamic Sessions: Tailors UI and URL parameters based on user login state.

Smart Inquiry Form: Pre-fills user details with structured package/destination selection.

Real-time Alerts: Trigger-based SweetAlert2 popups for login and signup feedback.

Modal Auth Flow: Seamless client-side toggling between Login and Sign-up forms.

Resilient Media: Built-in client-side image fallback handling.

Tech Stack
Frontend: HTML5, CSS3, JavaScript (ES6+), SweetAlert2

Backend: PHP

Database: MySQL
